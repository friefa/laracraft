# M0 – Fundament: Demo und bekannte Lücken

Stand: 2026-11-03 · Branch `claude/peaceful-archimedes-3vk3n8`

## Demo

1. `pnpm install && pnpm exec nx serve laracraft` → App-Shell mit Sprachumschaltung (de/en, ohne Reload),
   Disclaimer im Footer, Credits-Seite aus dem Lizenz-Manifest (Screenshot: `m0-credits-de.png`).
2. `pnpm exec nx run-many -t lint typecheck test build validate` → 8 Projekte grün.
3. CI auf GitHub: Format, Lint, Typecheck, Tests, Web-Build, **Android-Debug-APK** und **iOS-Simulator-Build**
   (erstmals grün im Lauf zu Dependabot-PR #1).
4. Engine: `libs/core-model` mit Blockregistry (202 Java-Blöcke inkl. Redstone, mit Build-Order-Metadaten),
   `BuildDocument` (16³-Chunks, ChangeSet/Undo) und Dateiformat v1 (ADR-0001), gehärtet nach unabhängigem Review.
5. `pnpm exec nx run textures:validate|atlas|credits` → Manifest-Prüfung, Atlas, Credits/LICENSES.md.

## Ergebnis der Reviews

- **Format/Dokument (P0.2r):** 12 Befunde, u. a. Dekompressionsbombe, nicht wieder ladbare Dateien bei
  nicht-kanonischen Zuständen, Koordinatenüberlauf, Prototype-Chain-Lookups. Alle behoben, Regressionstests vorhanden.
- **Registry (P0.3r):** keine falschen Properties/Defaults bei den Kernblöcken. Lichtwerte von Fackel und Lampe
  korrigiert. Vertragsgrenzen für M2 dokumentiert (siehe Roadmap „Bekannte Lücken“).

## Bekannte Lücken

- **Texturen:** Pixel Perfection Legacy (CC BY-SA 4.0, ADR-0003 angenommen) importiert: 174 von 175 benötigten
  Texturen, Autorenschaft pro Datei im Manifest (65 XSSheep, 109 Legacy-Mitwirkende). Es fehlt `chest`. Lizenzbestätigung
  durch Nova_Wostra steht aus (Aufgabe PO). Restpunkte siehe Roadmap „Bekannte Lücken“.
- **Minecraft-Version:** Registry geprüft gegen 1.21.x; aktuell ist Java 26.x (Frage 1, Paket P1.10).
- **Registry-Vertrag:** `solid` ist zu grob für Survival-Regeln (Support-Profile pro Fläche nötig); einige
  Platzierungsdetails (Redstone-Punkt/Kreuz, Schienenausrichtung, Türscharnier) noch nicht ausdrückbar → P2.0.
- **Format:** Bytes nach dem Ende des DEFLATE-Streams werden ignoriert statt abgelehnt (harmlos, dokumentiert).
  Bauten > 1024 pro Achse brauchen ein späteres Format v2.
- **Backend:** `apps/api` existiert noch nicht (M3); im Container ist kein .NET SDK installiert.
- **App:** Datentexte aus `credits.json` (z. B. „Änderungen“) sind nur englisch; `credits.json`-Typen sind im App-Code
  dupliziert (später gemeinsame Lib). App-Icons und Splash-Screens sind noch die Capacitor-Standardbilder.
- **CI:** Läufe auf `push` und `pull_request` können doppelt laufen; Performance-Budgets (Mesh-Zeit) kommen in M1.
- Alle ADRs sind **Vorgeschlagen**, bis der PO sie freigibt.
